KOLONKA CONTROL — демонстрационное Android-приложение

Что это:
- Настоящее Android-приложение (не HTML и не веб-страница).
- Разделы: Главная, Эквалайзер, Подсветка, Экран.
- Сейчас все органы управления демонстрационные: ESP32 и аудиотракт не подключены.

Как получить APK с телефона (без компьютера):
1. Создай бесплатный аккаунт GitHub, если его ещё нет.
2. В браузере телефона открой GitHub и создай новый пустой репозиторий (например kolonka-control).
3. Загрузи в репозиторий ВСЁ содержимое этой папки, сохранив структуру папок и файлов.
4. Открой вкладку Actions → Build Kolonka Control APK → Run workflow.
5. Когда сборка закончится зелёным статусом, открой её и скачай артефакт KolonkaControl-debug-apk.
6. Распакуй скачанный архив и установи app-debug.apk. Android может попросить разрешить установку из этого браузера/файлового менеджера.

Важно:
- Это debug APK для тестирования, не публикационная версия.
- Артефакт GitHub Actions хранится 14 дней.
- Для настоящего управления колонкой позже потребуется согласовать протокол ESP32-S3 и аппаратную часть.
